# Changelog

## 1.0.0 — 2026-09-10

### Added

- Reproducible Python project metadata in `pyproject.toml`.
- Runtime and development dependency definitions.
- Stable `python -m youtube_downloader` entry point.
- Windows `run.bat` and `build.bat` helpers.
- PyInstaller specification for Windows packaging.
- Inno Setup installer configuration.
- Project and runtime manifests.
- Smoke tests and GitHub Actions CI.
- Installation and FAQ documentation.

### Preserved

- Existing downloader application behavior and the original project archive already present in the repository.
- Existing repository documentation, contribution guidance, security policy and license files.
